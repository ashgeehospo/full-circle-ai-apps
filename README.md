# Full Circle Hospitality – AI app list

The public list of AI apps recommended by Full Circle Hospitality, shown on the website.

- `apps.json` – the live list the website reads. Updated automatically each day from the Hospo AI Shortlist register (apps marked "In programme" or "Shortlist"). Don't edit it by hand; changes are overwritten by the next sync.
- `embed.html` – the code pasted into the website's Squarespace Code Block.
- `scripts/build_public.py` – turns a dump of the register into `apps.json`.

Published at https://ashgeehospo.github.io/full-circle-ai-apps/apps.json
